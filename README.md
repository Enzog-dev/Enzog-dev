## 🚀 O que eu faço

A minha jornada abrange diferentes vertentes da tecnologia, garantindo uma visão de ponta a ponta sobre como os sistemas operam:

- 💻 **Sistemas e Backend** 》 Desenvolvimento de regras de negócio e modelagem de banco de dados utilizando **Java** e **MySQL** com arquitetura MVC.
- 🌐 **Aplicações Web** 》 Criação de páginas responsivas e manipulação do DOM no lado do cliente com **JavaScript Vanilla**, **HTML5** e **CSS3**.
- 🖥️ **Infraestrutura e Redes** 》 Planejamento de redes (Hub-and-Spoke), segmentação por VLANs, análise de vulnerabilidades e estudo de servidores em Cloud (**GCP** e **AWS**).
- 🎮 **Programação e Lógica** 》 Exploração de algoritmos e mecânicas estruturadas (como o desenvolvimento de jogos em **Lua**) e resolução prática de problemas de TI.
